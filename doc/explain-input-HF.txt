There are three entries for input to the 1D HF program,
1. logical switch variables at compile time, 
2. variables from an input file read via standard input, and
3. special parameters for HFB calculations are entered
   through the file 'hfbparams' residing in the working
   working directory.

The logical switches at compile time are set in 'params.inc':
=============================================================
  TPHPAIR   switches type of pairing cutoff,
             .TRUE.   activates cutoff on the pairing gap and u*v
             .FALSE.  activates cutoff on the occupation v**2
  TREGPAIR  switches to regularized pairing
  TLOWERCUT switches to make the cutoff symmetric about the
            Fermi energy
  TFORMW    activates computations of weak-charge formfactor
There are many more basic setting in 'params.inc' for grid size
and wavefunction space, for details see the comments in 'params.inc'.

We are now repeating the input line by line and provide explanations 
for each input variable. 
Some variables are experience-settings which should taken as
proposed. These are marked as D (=default) in the first column of the
explanations.
An extensive explanation of the variables is found in the header
of 'hafbody.for'.

HFB parameters are read from 'hfbparams' which looks as:
========================================================

------ single line ------------------------------------------------------
1000,10,1,2.0,500         iterhfb,iternat,modnat,pairenhance,iterbcs
-------------------------------------------------------------------------

 iterhfb       nr. of initial iteration in which pairuing strength is
               gradually reduced from enhance to normal value.
 iternat       nr. of subiterations in the HF accelerator.
 modnat        modulus with which the occelerator is invoked.
 pairenhance   initial pairing enhancement factor.
 iterbcs       nr. of initial BCS iterations.

Pairing enhancement and initgial BCS iterations serve to avoid
state-wise HFB pairing collapse.
